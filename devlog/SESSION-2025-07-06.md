# Session Summary — July 6, 2025

## Schema Design Decisions

### 1. MediaType as Enum
- The `mediaType` field on `Source` will be an enum (e.g., 'website', 'book', 'video', 'podcast', etc.).

### 2. Entities Table for Flexible Roles
- Instead of a dedicated `Author` table, introduce a generic `Entity` table (for people, organizations, etc.).
- Add a join table (e.g., `SourceEntity`) with a `role` field (e.g., 'author', 'translator', 'publisher') to support many-to-many relationships and flexible roles between sources and entities.

### 3. Full-Text Search
- Plan to add a full-text search index on relevant fields (e.g., `Clip.content`, `Source.notes`, etc.) for efficient searching.

## Initial Data Model (Drizzle ORM, TypeScript)

### Source
- id (UUID, PK)
- title (string)
- mediaType (enum)
- url (nullable)
- isbn (nullable)
- notes (text, optional)
- publicationDate (nullable)
- createdAt, updatedAt (timestamps)

### Clip
- id (UUID, PK)
- sourceId (FK to Source)
- content (text)
- note (text, optional)
- timestamp (nullable, for video/audio)
- pageNumber (nullable, for books)
- createdAt, updatedAt (timestamps)

### Tag
- id (UUID, PK)
- name (unique)
- description (optional)

### Entity
- id (UUID, PK)
- name (string)
- url (optional)
- notes (optional)

### SourceEntity (Join Table)
- sourceId (FK to Source)
- entityId (FK to Entity)
- role (enum: 'author', 'translator', 'publisher', etc.)

### Relationships
- Source <-> Tag: many-to-many
- Clip <-> Tag: many-to-many
- Source <-> Entity: many-to-many with role
- Source <-> Clip: one-to-many

### Full-Text Search
- Add search index on `Clip.content`, `Source.notes`, and possibly `Source.title`.
